# Reference guide

The [R8 bibliography](../References/R8_BIBLIOGRAPHY.md) indexes the manuscript’s 209 numbered entries. 103 entries have a matched DOI record in this archive. Entries without a verified match retain the manuscript bibliographic text. The number is the R8 bibliography number and can differ from a numeric EndNote filename or an earlier draft number.

## EndNote import

- Download the [R8 tagged import collection](../EndNote_Library/Tagged_Imports/R8). For the complete supplied set in one operation, import the combined .enw file using EndNote Import with UTF-8. Use a fresh library or enable duplicate discarding. Use the individual .enw files for inspection or targeted import.
- For the existing [R7 native library](../EndNote_Library/Native_R7), download the entire folder. Keep the .enl file beside the identically named .Data directory, including both databases in its sdb subfolder. Open the .enl in EndNote. Preserve a working copy when testing imports or editing records.
- Use Word with EndNote Cite While You Write to inspect fields or regenerate the bibliography in a working copy of the DOCX. The R8 package contains EndNote citation and bibliography fields. The R7 [completion audit](../Supplementary_Materials/R7/EndNote%20completion%20audit.md) documents the earlier live workflow, including the embedded Traveling Library and Numbered style.
- The R7 audit records the duplicate paper in files 150.enw and 151.enw and recovery of original manuscript reference 146. The supplied import files are preserved, including exact duplicates and supplemental scholar exports. [Recovered publisher record](https://doi.org/10.1016/j.ensm.2021.04.047).

The [citation maps](../References/Citation_Maps) are revision-specific. To attribute a panel in the current manuscript, start with [R8 figure source mapping](FIGURE_SOURCE_MAPPING.md).
