# Data description

This archive supports a literature review. It contains evidence used to summarize published studies, plus data about citations and manuscript preparation. The supplied materials contain no standalone raw experimental measurements, numerical curve source files, analysis notebooks or independent experimental replication package.

| Material | Format and use |
|---|---|
| Comparative results from cited studies | Read the five tables in the R8 Word (Manuscript/Manuscript 10 Nov.docx, staged locally) or [PDF](../Manuscript/Manuscript%2010%20Nov.pdf) manuscript. Interpret quantities using the original study’s units, testing conditions and protocols. |
| Citation number maps | [CSV files](../References/Citation_Maps) with headers and version-specific original-to-revised numbering. Import as comma-delimited UTF-8. Use the R7 map for the R7 EndNote workflow and the R8 bibliography for R8 caption citations. |
| Figure evidence | Download the R8 figure assets (Figures/R8, staged locally) or trace a chart, micrograph or diagram through the [source mapping](FIGURE_SOURCE_MAPPING.md) to the relevant published study. Raster charts preserve the supplied pixels and carry no recoverable original numeric series. |
| Workflow evidence | The [supplementary folder](../Supplementary_Materials) contains reference-matching records, preservation checks, scripts and layout previews. The R7 automation targets Word and EndNote on Windows and records the original workflow. Its compatibility on other setups has not been verified. |

Where a study provides numerical data or repository deposits, use the corresponding publisher record and its data-availability statement. Figure images can be inspected or compared with the papers using the [bibliography](../References/R8_BIBLIOGRAPHY.md).
